# Fazaia College Student Registration Form

A clean and professional student registration form built with HTML and CSS.

## Features
- Personal information fields
- Academic details including roll number and department
- Emergency contact section
- Responsive design for desktop and mobile

## Run locally
Open [index.html](index.html) in your browser.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Push this folder to the repository.
3. In GitHub, go to Settings > Pages.
4. Select the main branch and root folder.
5. Your site will be published at your GitHub Pages URL.
